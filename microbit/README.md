# micro:bit 연결 — DS 센서 세트에 한 줄 추가

교실 온도 처방전은 micro:bit가 USB로 보내는 줄을 읽는다(크롬의 Web Serial, 115200).
DS가 데이터를 모을 때 쓴 micro:bit 프로그램은 **그대로 두고**, 5분마다 기록하는 곳 바로 뒤에
"같은 값을 USB로도 보내기" 한 줄만 넣는다.

## 보내는 줄 모양 (셋 중 하나면 됨)

| 모양 | 예 | 설명 |
|---|---|---|
| 4개 | `21.43,40.2,1012.3,3` | 온도(°C), 습도(%), 기압(hPa), 움직임 횟수 — **이 순서** |
| DS 기록기 10열 | `302.19,2,,19.24,42.8,1012.4,21,16,5,2` | DS 데이터와 같은 열 순서. datalogger의 '시리얼로도 보내기'를 켜면 이렇게 나옴 |
| 열 이름 + 값 | `temp_C,humid_pct,press_hPa,motion` 다음 줄부터 값 | 첫 줄 이름대로 읽음 |

## 블록으로 넣기

1. MakeCode에서 DS 프로그램을 연다.
2. 5분마다 `기록(log data)` 하는 블록 바로 아래에 **고급 → 시리얼 → `시리얼 출력 문자열`** 블록을 넣는다.
3. 그 안에 `문자열 합치기`로 **온도 , 습도 , 기압 , 움직임**을 쉼표로 잇는다.
   온도·습도·기압은 DS 프로그램이 이미 쓰는 **센서 확장 블록**을 그대로 쓴다.
   ⚠️ micro:bit 본체의 `입력 → 온도` 블록은 1°C 단위라 AI 예측이 안 된다. 꼭 센서 확장 블록.
4. 움직임은 DS 프로그램이 5분 동안 센 횟수(기록하는 값과 같은 것).

## 자바스크립트로 보면 (예시 — 변수 이름은 DS 프로그램에 맞게)

```js
// 기존: 5분마다 datalogger.log(...) 하는 곳 바로 다음 줄
serial.writeLine(temp + "," + humid + "," + press + "," + motionCount)
```

## 확인

- micro:bit를 교실 노트북에 USB로 꽂고, 서비스에서 **micro:bit 연결** → 장치 고르기.
- 다음 기록 때(최대 5분) 실내 온도가 화면에 뜨면 성공(테스트 T5).
- 30분(기록 6개)이 쌓이면 **AI · 30분 뒤 예상**이 나온다.
- 다른 프로그램(MakeCode 등)이 같은 USB 포트를 잡고 있으면 연결이 안 된다 → 그 창을 닫고 다시.
